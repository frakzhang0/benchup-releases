# BENCHUP Skill 与安装下载

当前版本：**3.0.93**。研究进度可直接查看已有创新点。该版本改进了计算核验、反复挖掘和断点恢复。

仅发布安装说明、编译安装器及校验信息，科研引擎与后端源码保留在私有仓库。

Windows x64 联网安装器可以直接运行，无需预装 Python。Gitee 提供小安装器，完整运行组件统一由 GitHub Releases 分发。

## GitHub Agent 安装提示词

> 请从 https://github.com/frakzhang0/benchup-releases 读取 SKILL.md，在本机安装 BENCHUP Skill（Windows x64）。下载编译安装器 BENCHUP-SkillInstall.exe，按官网版本清单校验后，用 start --session 指定当前对话并启动。安装器会下载并校验运行组件，无需预装 Python。请在你的内置网页中打开启动命令返回的工作台，指导我在 https://benchup.cn 登录或注册并确认连接，再返回工作台。科研服务使用官网账号和贝壳。等我指定数据和研究目标后，再提交研究任务，并在工作台显示真实进度、图表和成果。
